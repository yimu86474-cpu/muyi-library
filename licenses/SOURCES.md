CPython 3.14.10 的许可证来自实际打包的 Python 安装。Windows 标准库依赖版本见 [CPython Windows 构建来源](https://github.com/python/cpython/blob/v3.14.10/PCbuild/get_externals.bat)，Mac 对应版本见 [CPython Mac 构建来源](https://github.com/python/cpython/blob/v3.14.10/Mac/BuildScript/build-installer.py)。PyInstaller、Psycopg、typing-extensions、certifi 以及 Windows 的 tzdata 随各自 Python 发行包复制许可证。Vue 和 hls.js 的声明来自锁定版本的 npm 发行包。OpenSSL 许可取自打包 Python 所用的对应 OpenSSL 版本，版本和源码见安装包的 `licenses/OpenSSL-SOURCE.txt`。

CPython 的许可证来自实际打包的 Python 安装。PyInstaller、Psycopg、typing-extensions、certifi 以及 Windows 的 tzdata 随各自 Python 发行包复制许可证。Vue 和 hls.js 的声明来自锁定版本的 npm 发行包。OpenSSL 许可取自打包 Python 所用的对应 OpenSSL 版本，版本和源码见安装包的 `licenses/OpenSSL-SOURCE.txt`。
